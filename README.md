# Customer Segmentation Analysis

## Project Overview

This project focuses on analyzing customer data and segmenting customers based on key business and customer attributes. The analysis was performed using Microsoft Excel to identify customer patterns, segments and business performance.

## Objectives

The main objectives of this project are:

* Analyze customer characteristics and behavior
* Identify different customer segments
* Calculate and analyze key performance indicators
* Understand customer distribution across different segments
* Generate meaningful business insights
* Support data-driven decision making

## Tools Used

Microsoft Excel

Excel functions and formulas

Pivot Tables

Data Cleaning

KPI Analysis

Dashboard Creation

Data Visualization

## Project Workflow

The project follows these steps:

1. Data Collection
2. Data Cleaning and Preparation
3. KPI Analysis
4. PivotTable Analysis
5. Customer Segmentation
6. Dashboard Creation
7. Business Insights

## Workbook Structure

Data contains the original dataset.

Cleaned_Data sheet contains the cleaned and prepared dataset.

KPIs sheet contains the key performance indicators calculated from the data.

Pivot_Data sheet contains PivotTable-based analysis.

Dashboard sheet contains the final visual representation of the analysis.

## Key Analysis

The project analyzes customer distribution, customer segments, key KPIs and other relevant business metrics to identify patterns and trends in the data.

## Outcome

This project demonstrates practical Excel data analysis skills, including data cleaning, PivotTable analysis, KPI calculation, customer segmentation and dashboard development. The analysis converts raw customer data into useful business insights for better decision making.
